## 🚀 Featured Projects

### 1. PulseOps — Real-Time Service Monitoring Platform

A full-stack infrastructure monitoring platform for tracking HTTP health, analyzing latency, simulating failures, and managing incident recovery.

**Tech Stack:** React, Vite, Node.js, Express.js, MongoDB Atlas, Socket.IO, HTTP/HTTPS, Vercel, Render.

**Key Features**
- Real HTTP health checks with configurable endpoints and timeouts.
- Periodic monitoring and historical latency metrics.
- Interactive charts showing average, minimum, and maximum latency.
- Real-time service-state updates through Socket.IO.
- Failure simulation, incident creation, and recovery workflows.
- Metric retention and defensive endpoint validation.

**System Design Concepts**
- Modular architecture and separation of concerns.
- Asynchronous operations and concurrent health checks.
- Event-driven communication.
- Observability and historical metric collection.
- Failure thresholds, incident lifecycle, and recovery handling.
- Timeout handling and defensive network validation.

🌐 **[Live Demo](https://pulse-ops-ten.vercel.app)**  
💻 **[GitHub Repository](https://github.com/VatsalNegi/PulseOps)**  
⚙️ **[Backend Health Check](https://pulseops-api-bea2.onrender.com/api/health)**

### 2. AgentHire AI — Agentic AI Interview Platform

An AI-powered interview platform designed to support interview workflows through document retrieval, contextual question answering, and candidate evaluation.

**Tech Stack:** Python, FastAPI, PostgreSQL, pgvector, SQLAlchemy, Sentence Transformers, OpenRouter, RAG.

**Key Features**
- Retrieval-Augmented Generation (RAG).
- Document processing and chunking.
- Semantic embeddings and vector similarity search.
- Context-aware LLM responses.
- Interview sessions, questions, candidate answers, and evaluations.
- Persistent storage for interview and document data.

**Concepts Explored:** Vector search, semantic retrieval, LLM integration, backend API design, and modular AI services.
